# MarkMate 📚

MarkMate is a simple Student Marks Calculator built using HTML, CSS and JavaScript.

## Features

- Enter marks for three subjects
- Calculate total marks
- Calculate average marks
- Calculate percentage
- Simple and responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was created as a beginner-friendly demonstration of how a small coding project can be built, documented, uploaded to GitHub and deployed as a live website.
